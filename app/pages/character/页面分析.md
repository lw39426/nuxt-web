# 原神角色展示页面架构分析与实现

## 1. 核心设计理念 (Core Concept)

本页面复刻了原神官网的角色展示交互，旨在打造沉浸式、视觉导向的用户体验。核心设计理念包括：

- **沉浸式背景 (Immersive Background)**：全屏背景按地区切换，统一视觉基调。
- **分层式舞台 (Layered Stage)**：背景、导航、信息、立绘、底部选择器分层渲染。
- **并发交叠转场 (Cross-fade & Slide)**：旧元素退场与新元素进场并发执行，减少“断帧感”。
- **路由驱动状态 (Route-Driven State)**：`path + query` 即页面状态，可直接分享与回放。

---

## 2. 路由与数据结构 (Routing & Data)

### 2.1 路由设计

页面为动态路由：`/character/[id]`

- **Path 参数 `id`**：地区英文名（如 `mondstadt`、`liyue`）
- **Query 参数 `char`**：角色索引（如 `?char=0`）

切换地区 = 路由主段变化；切换角色 = query 轻量变化。

### 2.2 数据模型（当前项目实际）

由 `useCharacterData` 提供：

```ts
interface Character {
  id: number
  name: string
  element: string
  cv: string
  description: string
  quote: string
  image: string
  avatar: string
}

interface Region {
  id: number
  name: string
  englishName: string
  background: string
  characters: Character[]
}
```

## 3. UI 布局与实现一体化说明 (Layout + Implementation)

> 本节按视觉层级说明「功能视觉」+「怎么实现」+「切换时发生什么」，避免上下跳读。

### 3.1 背景层 (Layer 0)

**布局目标**

- 全屏背景图 + 巨型英文水印。
- 不抢主体内容视觉，背景透明度保持较低。

**实现方式**

- 背景图与水印都使用 `<Transition :css="false">`。
- 通过 `:key="bg-${currentRegion.id}"`、`:key="wm-${currentRegion.id}"` 触发节点替换。
- 使用 GSAP hooks：
  - 背景：`onBgBeforeEnter` / `onBgEnter` / `onBgLeave`
  - 水印：`onMarkBeforeEnter` / `onMarkEnter` / `onMarkLeave`

**切换时序**

1. 地区变化后，旧背景先淡出。
2. 新背景淡入到 `opacity: 0.6`。
3. 水印轻微位移 + 淡入，形成空间层次。

### 3.2 左侧地区导航 (Layer 1)

**布局目标**

- 固定左侧，作为地区一级入口。
- 当前地区与非当前地区视觉差异明显。

**实现方式**

- 点击事件调用 `switchRegion(region.id)`。
- 路由更新为 `params.id=englishName`，并重置 `query.char=0`。
- 样式层通过条件类实现选中态（放大、透明度、描边）。

**切换时序**

1. 点击地区。
2. 路由变化触发 `currentRegionId` 更新。
3. `watch(currentRegionId)` 执行 `loadRegionData(newId)`。
4. 背景层与主体层按新地区数据进入转场。

### 3.3 主体内容区 (Layer 2)

**布局目标**

- 左侧信息（名称/CV/描述/台词），右侧立绘。
- 形成“信息先稳住、立绘强视觉冲击”的阅读动线。

**实现方式（状态）**

- `targetCharacter`：路由指向的目标角色。
- `displayCharacter`：当前真正渲染到 DOM 的角色。
- `watch(targetCharacter)` 先等待 `cacheImage(image/avatar)`，再把 `displayCharacter` 切到新角色。

**实现方式（动画）**

- 立绘 `<Transition>`：`onArtBeforeEnter` / `onArtEnter` / `onArtLeave`
  - 新图：右侧进入 + 淡入
  - 旧图：左侧退出 + 淡出
- 信息 `<Transition>`：`onInfoBeforeEnter` / `onInfoEnter` / `onInfoLeave`
  - 容器先进入
  - `.info-item` 再做 `stagger` 交错进入

**切换时序**

1. 点击头像更新 `query.char`。
2. `targetCharacter` 改变。
3. 预加载新图（命中缓存则几乎瞬时）。
4. `displayCharacter` 更新，引发旧节点 leave + 新节点 enter 并发。
5. 立绘与文本交错完成，形成“丝滑衔接”。

### 3.4 底部角色选择器 (Layer 3)

**布局目标**

- 低成本快速切人，不中断整体沉浸感。
- 通过高亮与 hover 动效传达可点击性。

**实现方式**

- `switchCharacter(index)` 只改 query，不做整页跳转。
- GSAP 微交互：
  - `onAvatarEnter`：头像上浮 + 轻微放大
  - `onAvatarLeave`：回弹到原位

**切换时序**

1. Hover 先给即时反馈。
2. Click 执行路由 query 切换。
3. 主体层启动角色切换链路。

## 4. 全局机制（跨层协同）

### 4.1 路由派生状态

- `currentRegionId` 从 `route.params.id` 派生（含数字兼容逻辑）。
- `charIndex` 从 `route.query.char` 派生。

### 4.2 资源预加载与缓存

- 运行时 `Map<string, HTMLImageElement>` 缓存图片。
- `cacheImage()` 支持 `img.decode()`，减少首帧闪烁。
- `onMounted` 后台预热其他地区资源。

### 4.3 并发竞争保护

- 使用 `switchToken` 防止快速连点导致旧请求回写新状态。

### 4.4 生命周期清理

- `onBeforeUnmount` 清理 GSAP 全局时间线，防止残留动画任务。

## 6. 后续可继续增强 (Future Improvements)

- **移动端适配**：改为纵向布局与不同断点动画参数。
- **可访问性**：为“减少动态效果”用户提供 `prefers-reduced-motion` 降级。
- **粒子与光效层**：添加轻量噪点、流光遮罩，增强官网级质感。
- **首屏骨架**：弱网条件下加入骨架与渐进加载提示。
