## 0. 模块映射约定（重要）

| YouMi 产品介绍中的概念 | 系统中的实际承载 | 说明 |
| --- | --- | --- |
| 角色展示（核心） | **商品模块**（`/products`、`/products/[id/code]`） | "角色"以商品数据形态承载，复用商品列表 / 详情 / 搜索接口 |
| 角色列表页 | **商品列表页**（`/products`） | 筛选维度需由"价格 / 品牌 / 内存"调整为"作品 / 类型 / 年代 / 标签" |
| 角色详情页 | **商品详情页**（`/products/[id/code]`） | 需增加角色资料区块与动效 |
| 专栏角色板块 | `character/[id].vue`（原神沉浸展示） | **暂不更改**，不在本清单范围 |
| AI 智能客服 | `/ai-page` | 已有，暂不更改 |
| 关于页 | `/about` | 已有，暂不更改 |

## 2. 任务明细

### M1 角色（商品）数据模型扩充 — P0 ✅ 已完成

- [x] **T1.1 商品数据模型增加角色属性字段**
  - 现状：`app/types/product.ts` 仅有 category / brand / memoryOptions / colorOptions 等电商字段
  - 新增字段：`ip`（作品/出处）、`characterType`（类型）、`era`（年代）、`tags`（标签）、`ratings`（人气 / 战力 / 智商 / 颜值人工评分）、`background`（背景）、`abilities`（能力）、`relationships`（关系）、`quotes`（名言）
  - 涉及：`app/types/product.ts`、`server/utils/mockStoreData.ts`、Flask 后端数据结构同步
  - 验收：详情接口返回新增字段，类型定义与 mock 数据一致
  - **实现说明**：字段复用 `brand`（作品）、`tags`（标签）、`description`（一句话简介），新增 `era`、`character_type`、`origin`、`background`、`highlights`（能力）、`ratings`（四维评分）、`relationships`、`quotes`；`server/utils/product.ts` 的 `normalizeProduct` 完成透传适配

- [x] **T1.2 搜索 / 筛选接口支持新维度**
  - 现状：`/product/search` 仅支持 q / 价格 / 品牌 / 内存 / 排序 / 分页
  - 新增参数：ip、type、era、tag（支持多选）
  - 涉及：`server/api/v1/product/search.get.ts`、Flask 后端、`app/composables/api/product.ts`（`ProductSearchParams` 扩展）
  - 验收：按作品 / 类型 / 年代 / 标签任意组合筛选返回正确结果
  - **实现说明**：`search.get.ts` 支持 `brand`（多选，复用承载 IP）、`era`、`character_type`、`tag` 逗号分隔多值筛选；curl 验证通过

- [x] **T1.3 录入 30-50 个多 IP 热门角色数据**
  - 覆盖：柯南、海贼、火影、龙珠、漫威、DC 等，每 IP 选 2-5 个代表角色
  - 每个角色含完整资料（背景 / 能力 / 关系 / 名言 / 出处）与四维评分
  - 验收：数据量达标，图片资源可用且注明出处
  - **实现说明**：录入 32 个角色，覆盖 8 大 IP（柯南/海贼/火影/龙珠/灌篮高手/漫威/DC/原神），均含完整角色资料与四维评分；图片策略为「无图不下发，后端录入后展示」

## 4. 建议实施顺序

```
M1（数据模型）→ M2（列表筛选）→ M3（详情增强）→ M4（首页卡片墙）

                     M5（对比）+ M6（排行）并行

                                  ↓
        M9 / M10 / M11 按需穿插，M12 上线前收尾
```
