## 1. 项目概述

### 1.1 产品愿景

NuxtWeb 是一个集**品牌营销、电商购物、内容博客、AI 智能对话、互动展示**于一体的综合性 Web 平台。产品以极致的用户体验和现代化的视觉设计为核心竞争力，面向 C 端用户提供流畅的浏览、购物与智能交互体验。

整体产品形态为"多场景 AI 驱动体验平台"，形成"情绪互动 → 内容理解 → 商业转化"的连续用户路径。

### 1.2 产品定位

| 维度       | 说明                                                       |
| ---------- | ---------------------------------------------------------- |
| 产品类型   | 综合型 Web 应用（SSR + CSR 混合渲染）                      |
| 目标市场   | 国内市场，面向年轻用户群体                                 |
| 核心价值   | 品牌展示 + 电商转化 + AI 赋能 + 内容运营                   |
| 差异化     | AI 智能助手贯穿全站、GSAP 电影级动效、明暗主题无缝切换     |
| 当前形态   | 前端高保真体验 + 后端可演进接口层，正从"产品化 Demo"向完整业务闭环演进 |

### 1.3 产品目标

1. 提供高品质的品牌营销着陆页，提升品牌形象
2. 搭建完整的电商购物流程（浏览 → 选购 → 下单 → 支付）
3. 通过博客内容运营吸引自然流量
4. 利用 AI 智能对话提升用户互动和留存
5. 通过互动展示（角色展示）增强用户粘性

### 1.4 当前交付范围

**已呈现范围（代码可验证）**：

1. 首页品牌化内容展示与 AI 问题入口
2. AI 多会话聊天（本地持久化、流式回复、错误重试）
3. 商品列表分组展示与商品详情交互（规格、服务、数量等）
4. 博客列表与详情展示（含无限滚动）
5. 角色页面（地区切换、角色切换、动画与预加载）
6. 登录/注册弹窗式认证（JWT 双令牌）
7. 主题模式切换（system/light/dark）与全局加载
8. 购物车与订单基础接口（已就绪，前端联动推进中）

**预留能力（不与已上线能力混淆）**：

1. AI 对话历史云端同步与多端一致性
2. 购物车与订单完整业务闭环（支付、售后）
3. 文章标签等扩展接口
4. 第三方登录（微信、GitHub、Google）与扫码/手机号登录落地

## 4. 功能详细说明

### 4.1 首页（`/`）

**功能描述**：品牌营销着陆页，承载用户第一印象与核心转化入口。

**页面结构**：
1. **Hero 英雄区**：全屏背景图 + 大标题 + 副标题 + AI 搜索输入框
2. **Logo 墙**：展示合作品牌/技术合作伙伴
3. **特性展示（Bento Grid）**：GSAP ScrollTrigger 驱动的网格特性介绍
4. **企业级功能区**：企业级功能介绍 + 客户案例大卡片
5. **客户案例区**：3 列客户实践案例卡片
6. **底部 CTA 区**：社交媒体滚动跑马灯 + 行动号召按钮

**关键交互**：
- AI 搜索输入框支持回车/点击跳转至 AI 对话页（query 参数注入首问）
- 背景图支持服务端动态配置（通过 `/home/config` 接口）
- 全站明暗主题自适应

### 4.2 商品商店（`/products`）

**功能描述**：Apple Store 风格的商品分类浏览页。

**页面结构**：
1. **头部区域**：渐变标题 + 促销信息 + 门店入口
2. **分类导航**：横向可滚动的分类图标列表，支持选中高亮
3. **商品系列展示**：每个分类一个系列块
   - 左侧大卡片：特色产品（占 3/5 宽度）
   - 右侧小卡片：其他产品（占 2/5 宽度，2 列网格）
   - 下方补充卡片：5 列网格

**数据来源**：
- 分类列表：`GET /api/v1/product/category/list`
- 分类商品：`GET /api/v1/product/category/:id/products`

### 4.3 商品详情（`/products/:id`）

**功能描述**：完整的商品信息展示与购买页面。

**页面结构**：
1. **面包屑导航**：首页 > 商品 > 当前商品名
2. **图片展示区（左侧 7/12）**：主图 + 缩略图列表
3. **商品信息区（右侧 5/12，Sticky 定位）**：
   - 标题 + 评分
   - 价格区（到手价 + 原价划线）
   - 优惠信息列表
   - 颜色选择器（色块按钮）
   - 版本选择器（网格按钮）
   - 数量选择器
   - 保障服务（可选勾选项）
   - 加入购物车 / 立即购买按钮
   - 服务保障列表
4. **商品亮点网格**：2×2 亮点展示
5. **商品详情区**：规格参数 + 商品描述（双列布局）
6. **推荐商品**：底部"你可能也喜欢"相关商品
7. **移动端底部操作栏**：固定在底部的加购/购买按钮

### 4.4 博客列表（`/blog`）

**功能描述**：内容博客列表页，支持分类筛选与无限滚动。

**页面结构**：
1. **Hero 文章**：大图特色文章卡片（全宽，图文叠加）
2. **分类筛选栏**：可点击的分类标签（全部、AI趋势、公告、工程、设计等）+ RSS 订阅入口
3. **文章网格**：2 列文章卡片网格
4. **无限滚动加载**：IntersectionObserver 触底加载

### 4.5 博客详情（`/blog/:id`）

**功能描述**：文章阅读详情页。

**页面结构**：
1. **返回按钮**：返回博客列表
2. **文章头部**：分类 + 日期 + 阅读时间 + 标题 + 作者信息
3. **特色图片**：全宽圆角大图
4. **正文内容**：Prose 排版样式的 HTML 内容
5. **分享栏**：Twitter / LinkedIn / 链接复制
6. **相关推荐**：底部 2 列相关文章

### 4.6 AI 智能对话（`/ai-page`）

**功能描述**：AI 聊天体验页面，独立的沉浸式界面。

**页面结构**：
1. 会话列表侧栏（多会话管理，本地保留最近 3 个）
2. 消息流区域（流式渲染、Markdown 预览、复制、错误重试）
3. 输入区（单条消息长度上限 4000 字符）

**特殊规则**：
- 隐藏导航栏和页脚（`hideNavbar: true, hideFooter: true`）
- 仅在客户端渲染（`.client.vue`），避免 SSR 下 AI SDK 报错
- 支持首页 query 注入初始问题，消费后自动清理 URL

**AI 模型支持**：
- 硅基流动（推荐）：Qwen/Qwen2.5-7B-Instruct 等
- OpenAI 兼容接口
- DeepSeek
- 阿里云百炼

### 4.7 角色展示（`/character/:id`）

**功能描述**：原神游戏角色互动展示页，支持地区切换与角色轮播。

**页面结构**：
1. **背景层**：地区背景图 + 地域名水印
2. **侧边栏**：地区列表（蒙德、璃月、稻妻、须弥、枫丹、纳塔等）
3. **角色信息区**：角色名 + CV 信息 + 元素类型 + 入队语音 + 描述 + 台词
4. **角色立绘区**：全屏角色图片
5. **底部轮播器**：角色头像卡片选择器

**特殊规则**：
- 强制使用胶囊导航栏样式（`forceCapsule: true`）
- GSAP 驱动的过渡动画（背景、立绘、信息均有独立动画）
- 图片预加载与缓存策略（全局缓存 + 移动端分级加载）
- 空闲时预加载下一区域资源；远端接口失败后回退本地 Mock

### 4.8 关于我（`/about`）

**功能描述**：个人作品集展示页，电影级叙事体验。

**页面结构（5 章叙事结构）**：
1. **第一章 - 英雄区**：全屏标题 + 粒子背景 + 旋转光环
2. **过渡 - 电影字幕**：上下遮幅 + 居中引语
3. **第二章 - 人物介绍**：个人信息 + 数据统计 + 技能标签浮动
4. **第三章 - 时间线**：经历时间线（左右交替布局）
5. **第四章 - 作品展示**：项目卡片网格
6. **第五章 - 联系我**：CTA + 底部版权

**特殊规则**：
- 独立主题切换按钮（页面内切换，不影响全局）
- GSAP ScrollTrigger 全页动画
- Canvas 粒子背景
- 噪点胶片质感叠加

### 4.9 用户认证系统

**功能描述**：登录/注册弹窗式认证系统。

**登录功能**：
- 用户名 + 密码 + 图形验证码登录
- 快速账号选择（演示用）
- 记住账号 / 忘记密码
- 手机号登录 / 扫码登录（预留入口）
- 第三方登录：微信、GitHub、Google（预留入口）

**注册功能**：
- 用户名 + 手机号 + 昵称 + 密码 + 确认密码 + 验证码

**认证机制**：
- JWT Token（access_token + refresh_token）
- Token 存储：内存 + Cookie 双写
- 401 静默刷新：自动使用 refresh_token 刷新，失败时弹出登录弹窗
- 请求去重：相同请求自动合并，防止并发竞态

### 4.10 购物车

**功能描述**：加购、改量、删除、清空能力，接口已就绪。

| 操作     | 方法   | 路径                     |
| -------- | ------ | ------------------------ |
| 列表     | GET    | `/miniapp/api/cart`      |
| 添加     | POST   | `/miniapp/api/cart`      |
| 更新数量 | PUT    | `/miniapp/api/cart/:id`  |
| 删除     | DELETE | `/miniapp/api/cart/:id`  |
| 清空     | DELETE | `/miniapp/api/cart/clear`|

### 4.11 订单管理

**功能描述**：创建、查询、取消、支付、确认收货能力，接口已就绪。

| 操作     | 方法 | 路径                             |
| -------- | ---- | -------------------------------- |
| 创建订单 | POST | `/miniapp/api/orders`            |
| 订单列表 | GET  | `/miniapp/api/orders`            |
| 订单详情 | GET  | `/miniapp/api/orders/:id`        |
| 取消订单 | POST | `/miniapp/api/orders/:id/cancel` |

## 6. 核心业务流程

### 6.1 购物流程

```
用户浏览首页/商店
    ↓
选择分类 → 浏览商品列表
    ↓
点击商品 → 进入商品详情页
    ↓
选择颜色/版本/数量
    ↓
[加入购物车] 或 [立即购买]
    ↓
(如需) 登录认证 → 弹出登录弹窗
    ↓
确认订单 → 创建订单（pending）
    ↓
支付订单 → 状态变为 paid
    ↓
确认收货 → 状态变为 completed
```

### 6.2 用户认证流程

```
用户触发需认证操作
    ↓
检查 authStore.isAuthenticated
    ↓
[已认证] → 继续操作
[未认证] → 弹出 AuthModal
    ↓
选择登录/注册
    ↓
填写表单 + 验证码
    ↓
提交 → 获取 access_token + refresh_token
    ↓
存入 Pinia Store + Cookie
    ↓
关闭弹窗，继续之前操作
```

### 6.3 AI 对话流程

```
用户在首页输入问题 / 点击 AI 入口
    ↓
跳转 /ai-page?question=xxx
    ↓
AI 页面加载（仅客户端渲染）
    ↓
初始化 AI 会话（Vercel AI SDK）
    ↓
发送消息 → 流式接收回答
    ↓
持续对话...（会话按最近更新时间持久化，本地最多 3 条）
```

### 6.4 内容浏览流程

```
用户进入博客列表
    ↓
```

## 10. 业务规则与约束

1. AI 功能受环境变量 `AI_ENABLED` 控制，可被全局关闭
2. AI 消息单条长度上限 4000 字符
3. AI 会话本地仅保留最近 3 个会话
4. 前端 API 统一要求响应结构 code/message/data
5. 页面可通过路由元信息控制导航栏、页脚和浮动菜单显隐
6. AI 心理陪伴场景需保留风险提示（建议寻求专业帮助）

## 11. 非功能性需求

### 11.1 性能要求

| 指标               | 目标值                    | 说明                     |
| ------------------ | ------------------------- | ------------------------ |
| 首屏加载（LCP）    | < 2.5s                    | SSR + 图片预加载优化     |
| 交互响应（FID）    | < 100ms                   | 客户端代码分割           |
| 布局偏移（CLS）    | < 0.1                     | 图片尺寸预定义           |
| 构建内存           | 4096MB                    | NODE_OPTIONS 配置        |
| 图片加载           | 懒加载 + 预加载           | loading="lazy" + cache   |
| 长页面渲染         | content-visibility 优化   | 降低渲染开销             |

### 11.2 可用性

1. 页面加载有可见反馈（全局加载看门狗，避免白屏挂死）
2. AI 异常具备可理解提示与重试入口
3. 核心入口在移动端可达

### 11.3 SEO 要求

- SSR 服务端渲染保证搜索引擎可抓取
- `useHead` 管理页面 meta 信息
- `robots.txt` 配置爬虫规则
- 语义化 HTML 标签使用

### 11.4 可访问性

- 图片 alt 属性
- ARIA 标签（role、aria-labelledby 等）
- 键盘导航支持（Tab、Enter）
- 色彩对比度满足 WCAG 标准

### 11.5 兼容性

- 现代浏览器（Chrome 90+, Firefox 90+, Safari 15+, Edge 90+）
- 移动端响应式（断点：sm 640px, md 768px, lg 1024px）
- iOS Safari 滚动兼容

### 11.6 安全与合规

1. Token 走 Bearer 头注入，不在前端硬编码敏感密钥
2. 服务端密钥仅在环境变量维护

### 11.7 监控与埋点

- **Sentry**：错误监控 + 性能追踪（tracesSampleRate 生产 10%，开发 100%）
- **自研 Tracker SDK**：用户行为埋点（page_view, click, expose, custom, error）
  - 批量上报（batchSize: 10, flushInterval: 3s）
  - 会话管理 + 设备标识
  - 空闲超时（30 分钟）

## 14. 风险与应对

1. **风险**：前端接口定义与后端实现进度不一致，联调成本上升
   - 应对：建立 API 状态矩阵（已实现/开发中/预留）并周更
2. **风险**：AI 服务受外部模型可用性影响
   - 应对：模型降级、错误码标准化、可观测日志
3. **风险**：多主题 + 高动效可能带来中低端设备卡顿
   - 应对：移动端降级策略与性能预算控制
