# YouMi 产品介绍

> 角色百科 · 沉浸式浏览 · 内容社区
> 面向动漫 / 影视爱好者的互动内容平台

---

## 一句话介绍

**YouMi** 是一个面向动漫 / 影视爱好者的角色百科与沉浸式浏览平台——用户在此探索精心策展的热门角色、享受电影级动效带来的探索乐趣，并阅读深度盘点内容；同时它也是独立开发者技术能力的立体作品集。

---

## 2. 产品愿景

YouMi 以极致的浏览体验与现代视觉设计为竞争力，面向动漫 / 影视爱好者提供沉浸式的角色探索与内容消费体验，同时通过签到、收藏等轻量机制建立用户回访习惯。

整体产品形态为 **"多场景 AI 驱动体验平台"**，形成 **"情绪互动 → 内容理解 → 习惯留存"** 的连续用户路径。

---

## 3. 产品目标

1. 提供高品质的角色展示与品牌级视觉体验，建立鲜明的站点认知；
2. 搭建完整的角色浏览体系（列表 → 详情 → 对比 → 排行），形成探索闭环；
3. 通过博客内容运营（盘点 / 解读 + 开发日志）吸引自然流量与两类受众；
4. 利用签到、收藏图鉴等轻量机制提升用户每日回访与留存；
5. 通过 AI 智能客服对话提升用户互动、推荐体验与站点好感度。

---

## 4. 目标用户

- **核心用户**：动漫 / 影视爱好者，喜欢浏览角色资料、做对比、看盘点榜单；
- **次要用户**：对现代 Web 动效与技术实现感兴趣的技术人群 / 招聘方；
- **特征**：年轻化、追求视觉体验、有一定收藏与打卡习惯。

### 核心用户路径

> 角色探索（内容吸引力）→ 收藏图鉴（占有欲驱动）→ 每日签到（习惯养成）→ 排行榜（虚荣心驱动）

四条环节串联形成完整的日活闭环；AI 客服作为辅助入口贯穿全程。

---

## 5. 功能模块

### 5.1 角色展示（核心）

- **首页**：精选角色卡片墙，首屏强视觉 + 动效引导
- **角色列表页**：支持按作品、类型、年代、标签筛选
- **角色详情页**：完整资料（背景、能力、关系、名言、出处），卡片翻转动效进入
- **角色对比页**：选取 2-4 个角色并排对比各项属性
- **角色排行榜**：按人气 / 战力 / 智商 / 颜值等维度排行（数据来自人工评分）

**初期数据**：人工精选录入 **30-50 个**热门角色，每 IP 选 2-5 个代表角色，覆盖柯南、海贼、火影、龙珠、漫威、DC 等。

### 5.2 内容博客

- **主方向**：角色盘点、作品解读、TOP 榜单类深度内容
- **辅方向**：站点开发日志、技术选型、迭代记录（呼应技术展示目的）
- 支持分类、标签、搜索、阅读量

### 5.3 互动体验

#### 5.3.1 动效驱动（探索感）

- GSAP 滚动触发动画、页面转场、卡片 3D 翻转
- 明暗主题无缝切换（详情页可跟随角色气质自动适配）
- 筛选 / 对比 / 排行三大功能性互动

#### 5.3.2 用户参与与留存

- **用户系统**：手机号 / 第三方登录（GitHub、微信），支撑收藏与签到
- **收藏图鉴**：收藏角色 / 文章形成个人图鉴，展示收集进度（如"已收集 32/50"）
- **每日签到**：签到领积分 / 徽章，连续签到天数奖励递增，打卡日历可视化
- **排行榜**：结合签到、收藏等行为形成轻量荣誉驱动

### 5.4 AI 智能客服（已有暂时不用更改）

| 项目 | 说明                                                         |
| ---- | ------------------------------------------------------------ |
| 形态 | 右下角悬浮客服式对话框（类 Intercom）                        |
| 能力 | 回答站点使用问题、推荐角色 / 文章、解释角色关系              |
| 技术 | 调用成熟大模型 API（如混元 / DeepSeek），服务端代理转发，Key 不暴露前端 |
| 数据 | 可检索站内角色 / 文章向量库，实现"基于内容的回答"            |
| 合规 | 标识"AI 生成内容，仅供参考"；敏感词过滤；留存对话日志        |

## 7. 合规清单

- [ ] 个人 ICP 备案（国内访问必需）
- [ ] 角色形象 / 名称使用需注明出处，声明"非官方粉丝站"，规避商用侵权风险
- [ ] 隐私政策 + 免责声明 + 用户服务协议页面
- [ ] 用户注册需手机号验证或第三方登录
- [ ] 积分 / 签到数据需防刷机制（IP + 频率限制）
- [ ] MVP 阶段不开放 UGC / 评论，规避内容审核压力
- [ ] AI 客服内容审核 + 标识 AI 生成

---

## 8. 明确不在 MVP 范围内

- ❌ 电商 / 支付 / 订单系统
- ❌ 评论 / 社区 / UGC（后续按需开放）
- ❌ AI 角色陪聊（仅保留客服形态，预留接口）
- ❌ 多语言（初期仅中文）
