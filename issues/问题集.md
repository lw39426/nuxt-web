## P001 - Mock 模式未生效（NUXT_PUBLIC_USE_MOCK=true 被忽略）

**日期**：2026-09-15
**阶段**：M5 对比页 + M6 排行榜联调期
**严重程度**：高（阻塞前端联调）

### 现象

`.env` 中已配置 `NUXT_PUBLIC_USE_MOCK="true"`，但所有 BFF 接口仍走真实 Flask 后端：

- 响应头 `X-Data-Source: backend`
- `[BFF][DEBUG]` 日志显示 `useMock = false boolean`（布尔 false，非字符串，说明根本没走到字符串路径）

### 排查过程

| # | 假设 | 结论 |
| --- | --- | --- |
| 1 | `.env` 内容错误（多处定义/BOM/CRLF） | 排除：仅一处定义，值正确 |
| 2 | `.env.local` 等覆盖文件 | 排除：Glob 确认只有 `.env` / `.env.example` |
| 3 | nuxt.config fallback 逻辑错误 | 排除：逻辑正确 |
| 4 | dev server 未重启 | 排除：冷启动多次仍复现 |
| 5 | Nuxt 环境变量不 coerce 字符串 | 排除：`isMockMode()` 已兼容，但运行时拿到的是布尔 false |
| 6 | Windows 用户级/机器级环境变量注入 | 排除：`[Environment]::GetEnvironmentVariable(..., 'User'/'Machine')` 均为空 |
| 7 | PowerShell profile 注入 | 排除：所有 profile 文件不存在 |
| 8 | **Trae 终端宿主进程注入** | **确认** |

### 根因

Trae 终端宿主进程向每个 PowerShell 会话持续注入 `NUXT_PUBLIC_USE_MOCK=false`：

- 会话内 `Remove-Item Env:NUXT_PUBLIC_USE_MOCK` 后立即回读仍为 `false`（被宿主持续注入，无法在会话内清除）
- Node 的 c12/dotenv 机制**不覆盖已存在的进程环境变量**，导致 `.env` 的 `"true"` 被进程级 `false` 压过
- nuxt.config 中 `process.env.NUXT_PUBLIC_USE_MOCK` 拿到 `"false"` → 三元判断 → 布尔 `false` → BFF 走真实后端

### 解决方案

在启动命令中显式覆盖进程环境变量（优先级高于宿主注入）：

```powershell
$env:NUXT_PUBLIC_USE_MOCK = "true"; npx nuxt dev
```

已固化到 [package.json](../package.json) 的 `dev:mock` 脚本：

```json
"dev:mock": "set NUXT_PUBLIC_USE_MOCK=true&& nuxt dev"
```

### 验证方式

```powershell
# 1. 响应头应为 mock
curl -s -D - http://localhost:3001/api/v1/product/search?pageSize=10 | findstr X-Data-Source

# 2. 页面数据：/rankings、/products 应显示柯南/海贼等 32 个 Mock 角色
```

### 经验教训

1. **Trae 管理的终端环境不可信**：会话内无法清除宿主注入的环境变量，需在启动命令显式覆盖
2. **进程环境变量优先级高于 `.env`**：Nuxt（c12）的 dotenv 机制不覆盖已存在的进程变量，排查"配置不生效"问题时应先检查 `$env:变量名`
3. **判断注入源的三步法**：查注册表持久层（User/Machine）→ 查 PowerShell profile → 查终端宿主进程

## P002 - CompareBar 组件无法解析（Vue 警告）

**日期**：2026-09-15
**阶段**：M5 浏览器回归
**严重程度**：低（控制台警告，悬浮栏未渲染）

### 现象

控制台警告：`Failed to resolve component: CompareCompareBar`，全局悬浮对比栏不渲染。

### 根因

Nuxt 组件自动注册时会**去重目录名与文件名的重复段**：`components/compare/CompareBar.vue` 注册为 `CompareBar`，而非 `CompareCompareBar`。[default.vue](../app/layouts/default.vue) 中误写成 `<CompareCompareBar />`。

### 解决方案

改为 `<CompareBar />`。

### 经验教训

`components/<目录>/<同名>.vue` 结构下，自动注册的组件名只保留一份前缀：`compare/CompareBar.vue` → `CompareBar`，不是 `Compare + CompareBar` 拼接。
