# 博客 Hero 轮播化改造 + 修复筛选跳顶问题（已实施）

> 状态：**已完成并验证**。本文档已按最终实现更新，包含四轮迭代：
> ① 轮播组件初版（淡入淡出）→ ② 滑动/拖拽手势支持 → ③ 轨道式衔接滑动改造 → ④ 克隆边缘实现首尾无缝衔接。

## Summary

博客列表页（`app/pages/blog/index.vue`）原有两个关联问题，均已解决：

1. **跳顶 bug（已修复）**：点击分类/标签筛选按钮时页面跳回顶部。根因是 `loadArticles(true)` 的 reset 逻辑立即清空 `displayedPosts`，导致 Hero 区（`v-if="heroPost"`）卸载 + 文章 grid 清空，文档高度骤降至约一屏（`min-h-screen`），浏览器将超界的 `scrollY` 钳制为 0；新数据到达后高度恢复但滚动位置不还原。全项目无任何主动滚动调用，纯高度塌陷引发。
2. **Hero 改造需求（已实现）**：Hero 大图区改为独立轮播板块，保留现有视觉样式，数据未加载时显示默认占位；后续追加要求支持触摸/鼠标滑动，且滑动时相邻图片**衔接出现**（轨道式），并最终要求**首尾必须无缝衔接**（从最后一张切到第一张不得倒带掠过中间图片）。

用户决策：
- 轮播数据**独立于筛选**（始终展示最新 5 篇，切换筛选时轮播不变）
- 轮播与下方列表**允许重复展示**（列表完整渲染，不做去重）
- 轮播支持**触摸滑动 + 鼠标拖拽**，拖拽时画面跟手、相邻图片衔接滑入（最终形态为轨道式滑动，非淡入淡出）
- 轮播**首尾必须无缝衔接**：从最后一张切到第一张时，视觉上应紧邻滑入，不允许出现"倒带掠过中间图片"

## 最终实现（Final Implementation）

### 1. `app/components/BlogHeroCarousel.vue` — 克隆边缘轨道式轮播（首尾无缝）

**结构**：容器（`overflow-hidden` + 比例占位）→ 轨道 div（`flex` 水平排列，整体位移）→ N 张 slide（`relative w-full shrink-0`）。

**克隆边缘（首尾无缝的核心）**：轨道实际渲染的不是原始数组，而是**首尾各克隆一张**：

```ts
/** 克隆轨道：[末页克隆, ...原数据, 首页克隆] */
const clonedTrack = computed<BlogPost[]>(() => {
  if (props.posts.length === 0) return [];
  const first = props.posts[0]!;
  if (props.posts.length === 1) return [first, first, first];
  const last = props.posts[props.posts.length - 1]!;
  return [last, ...props.posts, first];
});
```

- 假设原数据 `[P0,P1,P2,P3]`，克隆轨道变为 `[P3, P0, P1, P2, P3, P0]`
- **指针 `current` 有效范围 1~N**（1 对应真实 P0，N 对应真实 PN-1），而非 0~N-1
- 滑到最后一张继续向右 → 指针到 `N+1`（渲染的是克隆的 P0），动画结束后**瞬跳**回指针 `1`（同样是 P0），用户无感知
- 反向滑到第一张继续向左 → 指针到 `0`（克隆的 P3），动画结束后**瞬跳**回指针 `N`（同样是 P3）
- 这样左右两个方向都是"相邻图真实滑入"，彻底消除取模循环的倒带

> 注：`noUncheckedIndexedAccess: true` 使 `arr[i]` 推断为 `T | undefined`，故索引访问使用非空断言 `!`，并显式声明 `computed<BlogPost[]>` 返回类型。

**核心瞬跳逻辑（修复倒带的最终方案）**：

```ts
/** 轨道 DOM 引用（用于瞬跳时强制重排，提交无过渡基线） */
const trackRef = ref<HTMLElement | null>(null);

/**
 * 瞬跳到指定轨道位置（不播放动画）
 * 关键：仅设 transition:none 不够，必须在同一帧内强制重排，
 * 让浏览器把新位移提交为基线；否则恢复过渡后浏览器会把它当成
 * 一次位置变化而播放动画，从而出现"倒带掠过中间图片"。
 * @param target 目标轨道指针
 */
const jumpTo = (target: number) => {
  isResetting.value = true;
  current.value = target;
  nextTick(() => {
    // 强制重排：提交 transition:none + 新位移的基线
    void trackRef.value?.offsetWidth;
    isResetting.value = false;
  });
};

/** 跳转到指定真实索引（瞬跳，无动画） */
const goTo = (index: number) => {
  jumpTo(index + 1);
};

/** 轨道过渡动画结束时检查是否需要瞬跳到真实页（仅响应轨道自身的 transform） */
const onTrackTransitionEnd = (e: TransitionEvent) => {
  if (e.target !== trackRef.value || e.propertyName !== 'transform') return;
  if (current.value === props.posts.length + 1) jumpTo(1);
  else if (current.value === 0) jumpTo(props.posts.length);
};
```

**为什么 `nextTick` 不够**：Vue 的 `nextTick` 只等 DOM 更新，不等浏览器样式提交/重排。若在同一帧内先改位移再恢复过渡，浏览器会把「无过渡 + 新位移」与「恢复过渡」合并成一次位置变化，于是又播放倒带动画。因此必须读一次 `offsetWidth` 强制 reflow，把新位移提交为基线，再恢复过渡。

**正反向越界拦截**：

```ts
const next = () => {
  if (current.value >= props.posts.length + 1) return;
  current.value++;
};
const prev = () => {
  if (current.value <= 0) return;
  current.value--;
};
```

**`TransitionEvent` 过滤**：轨道上还挂着 slide 子元素，子元素自身的 transform 过渡会冒泡触发 `transitionend`。故在回调中校验 `e.target === trackRef` 且 `e.propertyName === 'transform'`，避免误判。

**轨道位移样式**：

```ts
/**
 * 轨道位移样式：
 * - 克隆轨道长度 = posts.length + 2，当前指针 1 对应真实首页
 * - 瞬跳重置时禁用过渡，实现无感跳转
 * - 拖拽跟手时禁用过渡保证即时响应
 */
const trackStyle = computed(() => ({
  transform: `translateX(calc(-${current.value * 100}% + ${dragOffset.value}px))`,
  transition: isResetting.value || dragOffset.value !== 0 ? 'none' : undefined
}));
```

**真实索引映射**（供指示点使用，屏蔽克隆边缘）：

```ts
/** 当前真实索引（0~posts.length-1），用于指示点 */
const realIndex = computed(() => {
  if (current.value === 0) return props.posts.length - 1;
  if (current.value === props.posts.length + 1) return 0;
  return current.value - 1;
});
```

- 轨道 class：`flex h-full transition-transform duration-700`（切换时 700ms 平滑滑动）
- 幻灯片：`NuxtLink` + UiImage 背景 + 渐变遮罩 + 日期/标题/摘要/作者 + ring 抗锯齿层（视觉沿用原 Hero）；`:key` 用 `` `${post.id}-${idx}` ``，因首尾克隆与原图 id 重复，需拼接索引保证唯一

**自动播放**：5 秒间隔；hover 容器暂停；单篇/空数据不播放；数据异步到达后 `watch` 启动（同时把指针复位为 1）。

**滑动/拖拽手势**（触摸与鼠标共用判定逻辑）：

| 项 | 实现 |
|---|---|
| 触摸 | `@touchstart.passive` / `@touchmove.passive` / `@touchend`（passive 不阻塞页面垂直滚动） |
| 鼠标 | 容器 `@mousedown`；`window mousemove`（跟手）+ `window mouseup`（兜底拖出容器释放） |
| 切换判定 | 水平位移 > 50px **且** 大于垂直位移才切换（防误触垂直滚动） |
| 跟手反馈 | `dragOffset` ref 实时更新，轨道 transform 叠加；限制在容器宽度一半内；垂直主导时不跟手 |
| **原生拖拽阻断** | 容器 `@dragstart.prevent` —— **关键修复**：slide 是 img，按住拖动会触发浏览器原生图片拖拽（dragstart→dragend 模式下不派发 mouseup），导致手势永不结束、切换失效 |
| click 误触抑制 | `swiped` 标志 + 容器 `@click.capture`：滑动后的第一次点击被拦截，防止松手误触 slide 链接跳详情 |
| 光标 | 多于一篇时 `cursor-grab active:cursor-grabbing select-none` |
| 手势期间 | 暂停自动播放，结束后恢复 |

**占位态**（`posts.length === 0`）：`absolute inset-0 bg-gradient-to-br from-gray-800 to-black` + 居中 `i-carbon-image text-8xl text-white/10`，保持容器比例不塌陷。

**箭头/指示点**（`v-if="interactive"`）：悬停浮现的左右箭头（`bg-black/30 hover:bg-black/50`）+ 底部指示点（active 拉伸为 `w-6` 胶囊），点击切换。

/** 加载 Hero 轮播数据（仅首次进入页面请求一次，失败静默由占位兜底） */

## Assumptions & Decisions

| 决策点 | 结论 | 依据 |
|---|---|---|
| 轮播数据源 | 独立请求最新 5 篇，不随筛选变化 | 用户选择"独立于筛选" |
| 列表去重 | 不去重，完整展示 | 用户选择"允许重复展示" |
| 自动播放 | 5 秒间隔，hover/手势暂停，单篇/空数据不播放 | 主流通例 |
| **过渡动画** | **轨道式整体滑动 700ms**（初版淡入淡出已在迭代③中替换） | 用户要求"滑动时看见相邻图片、右滑衔接出现" |
| **首尾衔接** | **克隆边缘（`[末页克隆, ...原数据, 首页克隆]`）+ 瞬跳重置**，指针有效范围 1~N | 用户要求"首尾必须无缝衔接，不能倒带掠过中间图片" |
| **瞬跳重置** | 设 `transition:none` 改位移后，**读 `offsetWidth` 强制重排**再恢复过渡 | 仅靠 `nextTick` 会让浏览器合并为一次位移变化、播放倒带动画 |
| **拖拽判定阈值** | 50px 且水平主导 | 主流通例，防垂直滚动误触 |
| **原生拖拽** | `@dragstart.prevent` 阻断 | img 原生拖拽吞掉 mouseup，鼠标拖拽失效的根因 |
| 组件位置 | `app/components/BlogHeroCarousel.vue` 根目录 | 与 BlogCard.vue 并列，符合现有惯例 |
| reset 失败行为 | 保留旧列表 + hasMore=false（与现状一致） | 避免过度设计 |
| 占位样式 | 渐变深色背景 + 图标（复用现有降级背景） | 用户"默认占位展示"要求 |
