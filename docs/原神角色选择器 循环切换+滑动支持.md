# 原神角色选择器：循环切换 + 滑动支持

## 问题根因（已确认）

角色选择器内联在 `app/pages/character/[id].vue`（无独立组件）：

1. **左右箭头被永久禁用**：箭头目前只负责"滚动头像条"（`slideCarousel` 增减 `carouselOffset`），且 `maxCarouselOffset = charCount - 6`；当前所有地区角色数 ≤ 6（蒙德 2、璃月 4、稻妻 2），偏移上限为 0，箭头 `:disabled` 后点了没反应。
2. **无循环**：到边界即禁用，不会回到第一项。
3. **无滑动**：全页无任何 touch/pointer 处理；头像条移动端靠原生 `overflow-x-auto` 滚动，桌面端鼠标无法拖动；主展示区不支持滑动切换角色。
4. **附带隐患**：`charIndex = parseInt(route.query.char)` 对 `?char=99`/`?char=abc` 无钳制，会进入"暂无角色"死状态。

用户已确认：箭头改为**切换上/下一个角色（循环回绕）**；滑动需要 **头像条鼠标拖拽** 和 **移动端主区域滑动切换** 两者。

## 改动（全部在 `app/pages/character/[id].vue` 单文件内）

### 1. 安全索引 + 循环切换（script）

- 新增 `charCount` computed（从 `regions.value[currentRegionSlug.value]?.characters.length ?? 0` 取，避免依赖后面声明的 `currentRegion`，规避 TDZ）。
- 重写 `charIndex`：`Number()` 解析 `route.query.char`，`NaN → 0`，并钳制到 `[0, charCount-1]`。越界/非法 URL 不再显示"暂无角色"。
- 新增 `selectNextCharacter()` / `selectPrevCharacter()`：`(charIndex ± 1 + count) % count` 循环回绕，内部复用 `switchCharacter`（router.push 写 URL，动画/预加载/watch 链路不变）。
- `preloadImages` 中原来的 `Number.isNaN(charIndex.value) ? 0 : ...` 兜底可简化（索引已保证安全）。

### 2. 头像条改为统一原生滚动 + 自动跟随（替代 transform 机制）

- **删除**整套 transform 偏移机制：`carouselOffset`、`CAROUSEL_VISIBLE_COUNT/_ITEM_WIDTH/_GAP/_STEP`、`MOBILE_CAROUSEL_*` 常量、`maxCarouselOffset`、`slideCarousel`、地区切换重置偏移的 watch 中的旧逻辑。`MOBILE_PRELOAD_LOOKAHEAD` 保留。
- 容器去掉 `sm:overflow-hidden`，桌面/移动统一 `overflow-x-auto snap-x snap-mandatory`（移动端原生滚动体验保留，桌面端获得可滚动能力）。
- 新增 `followActiveCharacter(behavior)`：用 `getBoundingClientRect` 计算激活头像与容器中心差值，`scrollTo` 平滑居中；并钳制到 `[0, scrollWidth - clientWidth]`。
- 触发时机：`watch(charIndex)`（含箭头循环、点击头像）；地区切换 watch 改为 `nextTick` 后瞬时跟随；`handleResize` 时瞬时跟随。
- 箭头模板：移除 `:disabled` 与 disabled 样式，改绑 `selectPrevCharacter` / `selectNextCharacter`，补 `aria-label`。

### 3. 头像条鼠标拖拽滑动（桌面端）

- 仅对 `pointerType === 'mouse'` 生效（触摸端继续走原生滚动，避免冲突）：
  - `pointerdown` 记录起点与 `scrollLeft`，`setPointerCapture`；
  - `pointermove` 位移 > 5px 标记 `dragMoved` 并实时写 `scrollLeft`（拖拽中 `cursor-grabbing`）；
  - `pointerup` 后按实测步长（相邻项 `offsetLeft` 差）四舍五入吸附到最近项（平滑滚动）。
- 容器加 `@click.capture` 捕获阶段拦截：发生拖拽后阻止随后的误点击（不触发切换角色），未拖拽时点击照常。
- 头像 `img` 加 `draggable="false"`，容器加 `select-none cursor-grab`，避免原生图片拖拽干扰。

### 4. 移动端主区域滑动切换角色（循环）

- 页面根元素挂 `@touchstart.passive` / `@touchend.passive`：
  - 起点 UI 过滤：手势起点位于头像条、侧边栏、地区下拉内（`closest('[data-swipe-exclude]')`）时忽略——这些区域外加 `data-swipe-exclude` 属性；
  - 终点判定：`|dx| ≥ 56px` 且 `|dx| > 1.5|dy|` 才算横向滑动；
  - 左滑 → 下一个角色，右滑 → 上一个角色，同样循环回绕。
- 页面本身不纵向滚动（h-screen overflow-hidden），无误触滚动冲突。

## 验证（`pnpm dev` + 浏览器实测）

1. 桌面端：箭头在最后一名角色时点右箭头回到第一项、第一项点左箭头到最后一项；URL `char` 参数同步；头像条平滑滚动使高亮项居中。
2. `?char=99`、`?char=abc` 不再出现"暂无角色"，回落到第一项。
3. 鼠标拖拽头像条：可拖动、松手吸附、拖拽后不误切角色、静止点击正常切换。
4. 移动端视口（触摸模拟）：主区域左/右滑切换角色并在边界循环；在头像条/侧边栏/下拉上滑动不触发切换，头像条原生滚动正常。
5. 全程控制台无报错；`pnpm lint` 通过。
