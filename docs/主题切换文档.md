# 主题切换（system / light / dark）功能文档

本文档说明：本项目如何实现主题切换、涉及文件与关键逻辑、以及未来需要调整时应该改哪里。

## 目标与约束

- 提供三态主题：`system`（跟随系统）、`light`（浅色）、`dark`（深色）。
- 主题切换需：
  - 立即生效（通过给根节点加/移除 `dark` class 触发 `dark:` 变体）。
  - 持久化保存（刷新后仍保持选择）。
  - `system` 模式下监听系统主题变化（`prefers-color-scheme: dark`）。

## 实现概览

本项目使用 UnoCSS 的 `dark:` 变体。

- 当 `document.documentElement`（`<html>`）存在 `class="dark"` 时，`dark:*` 样式生效。
- 当移除 `dark` 时，`dark:*` 样式不生效。

实现方式：

1. 用 Nuxt 的 `useState` 维护全局状态 `themeMode`。
2. 用 client 插件在浏览器端：
   - 从 `localStorage` 读取用户上次选择。
   - 监听 `themeMode` 变化并同步：
     - 写入 `localStorage`
     - 给 `<html>` 添加/移除 `dark` class
     - `system` 模式下订阅系统主题变化
3. UI（悬浮面板）：提供三按钮切换 `system/light/dark`，以及平滑滑出的侧边交互。

## 涉及文件

- 全局状态 composable：
  - `app/composables/useThemeMode.ts`
- 浏览器端主题同步插件：
  - `app/plugins/theme.client.ts`
- 主题切换 UI（右侧悬浮菜单）：
  - `app/components/AppFloatingMenu.vue`

## 关键代码说明

### 1) 全局状态：`useThemeMode()`

文件：`app/composables/useThemeMode.ts`

- `mode`：`useState<ThemeMode>('themeMode', () => 'system')`
- `setMode(value)`：修改 `mode.value`

说明：`useState` 在 Nuxt 中是全局共享状态，同名 key 会在全站复用。

### 2) 插件：`theme.client.ts`

文件：`app/plugins/theme.client.ts`

插件做三件事：

1. 初始化读取持久化：
   - 从 `localStorage` 的 `theme-mode` 读出 `system|light|dark`
   - 写入到全局 `themeMode`
2. 监听 `themeMode` 的变化：
   - 写入 `localStorage`
   - 如果是 `system`：根据 `matchMedia('(prefers-color-scheme: dark)')` 设置 `dark` class，并监听系统变化
   - 如果是 `light/dark`：直接强制设置 `dark` class，并取消系统监听
3. 对 DOM 的最终动作：
   - `document.documentElement.classList.toggle('dark', isDark)`

### 3) UI：右侧悬浮菜单 (AppFloatingMenu)

文件：`app/components/AppFloatingMenu.vue`

- 当前的主题切换功能集成在右侧的全局悬浮菜单中。
- **交互设计**：
  - 默认状态下，它是一个吸附在屏幕右侧边缘的半圆形把手，视觉克制，不遮挡核心内容。
  - 点击后，把手向右平滑隐藏，同时抽屉式面板从右侧平滑滑出。
  - **动画实现要点**：父容器不使用 `flex`（避免高度塌陷导致跳动），子元素（面板和按钮）均采用绝对定位 (`absolute`) 和 CSS `transition-all`（`translate-x` 与 `opacity`）独立控制显示隐藏，确保展开与关闭都极致流畅。
- 内部同样使用 `useThemeMode()` 获取 `mode` / `setMode`。
- 按钮根据当前 `mode.value` 高亮。
- 三个按钮含义：
  - `system`：跟随系统（图标使用 `i-carbon-screen`）
  - `light`：浅色（`i-carbon-sun`）
  - `dark`：深色（`i-carbon-moon`）

#### 3.1) 滑动指示块动画（性能友好）

文件：`app/components/AppFloatingMenu.vue`

UI 使用一个“滑动指示块”（`.theme-indicator`）来表示当前选中项。

- 指示块为 `position: absolute`，不会影响布局。
- 动画使用 `transform: translate3d(...)` + `transition-transform`，属于合成层动画（更不易引发卡顿）。
- 通过 CSS 变量 `--theme-index` 控制位置：
   - `system` => 0
   - `light` => 1
   - `dark` => 2

指示块位置计算（核心）：

- `transform: translate3d(calc(var(--theme-index) * 2rem), 0, 0);`

其中 `2rem` 对应单个按钮的“步进宽度”（当前按钮宽度 `w-8` = 2rem）。

> 兼容性：同时加了 `motion-reduce:transition-none`，用户系统开启“减少动态效果”时会自动关闭过渡。

## 本地验证步骤

1. 启动项目：
   - `pnpm dev`
2. 切换主题：
   - 点击右侧边缘的齿轮半圆按钮展开面板。
   - 点击面板中的三个按钮，观察页面 `dark:` 样式是否切换。
3. 刷新验证持久化：
   - 刷新页面，主题应保持不变。
4. 验证 `system`：
   - 切到 `system` 后，在系统设置中切换浅色/深色，页面应自动跟随。

## 未来调整指南（最常见需求）

### A. 修改默认主题

文件：`app/composables/useThemeMode.ts`

将：

- `useState<ThemeMode>('themeMode', () => 'system')`

中的默认值从 `'system'` 改为 `'light'` 或 `'dark'`。

> 注意：如果用户本地已有 `localStorage` 保存值，仍会优先使用保存值。

### B. 修改持久化 key / 禁用持久化

文件：`app/plugins/theme.client.ts`

- 修改 `STORAGE_KEY = 'theme-mode'`
- 若要禁用持久化：删掉或注释掉 `localStorage.getItem/setItem` 相关逻辑即可。

### C. 更换“系统”按钮图标

文件：`app/components/AppFloatingMenu.vue`

当前使用的是 Carbon 图标：`i-carbon-screen`

如果想换成其它 Carbon 图标（例如 `devices`），把 class 改为：

- `i-carbon-devices`

> 项目已引入 `@iconify-json/carbon`，不需要额外安装。

### D. 调整面板显示逻辑与动画

文件：`app/components/AppFloatingMenu.vue`

当前组件不仅包含主题切换，还包含了“回到顶部”等全局操作，采用了抽屉式交互。

**1) 面板的动画**
由 Vue 的 `<Transition>` 组件管理：
- `enter-active-class="transition-all duration-300 ease-out"` 
- `leave-active-class="transition-all duration-300 ease-in-out"`
修改这里的 `duration-*` 或 `ease-*` 可以调整展开/收起的节奏。

**2) 避免卡顿跳动的核心机制**
- 不要对控制显示/隐藏的元素使用 `v-show="!isOpen"` （`display: none` 会导致布局瞬间塌陷）。
- 应该使用 CSS 类 `opacity-0 pointer-events-none` 配合 `translate` 来做隐藏，并确保其处于绝对定位。

### E. 调整滑动动画（速度/缓动/尺寸）

文件：`app/components/AppFloatingMenu.vue`

常见可调项：

1) 动画速度与缓动

- 指示块 class 中：`duration-200 ease-out`
   - 更慢：`duration-300`
   - 更快：`duration-150`
   - 更“弹”：可以尝试 `ease-in-out`

2) 按钮尺寸改变后的位移步进

如果你把按钮从 `w-8` 改成其它宽度（比如 `w-9`），需要同步修改 `.theme-indicator` 的步进：

- `w-8` => `2rem`（当前）
- `w-9` => `2.25rem`
- `w-10` => `2.5rem`

对应修改这里：

- `.theme-indicator { transform: translate3d(calc(var(--theme-index) * 2rem), 0, 0); }`

3) 指示块样式

- 指示块背景/边框来自：`bg-white/20 border border-white/10`
- 如需更明显/更弱，改这两个 token 即可。

### F. 改成用 `data-theme` 而不是 `dark` class（不建议，除非你要统一其它库）

当前项目大量使用 `dark:`，它天然依赖 `dark` class。

如果要改：

- 需要同时调整 UnoCSS 的 dark mode 配置（`uno.config.ts`）与全站 class/选择器策略。
- 改动面很大，建议继续沿用 `dark` class。

## 常见问题排查

1. `dark:` 不生效
   - 检查 `<html>` 是否有 `dark` class（浏览器 DevTools Elements 面板）。
   - 确认 `app/plugins/theme.client.ts` 是否存在且文件名以 `.client.ts` 结尾（确保只在浏览器运行）。
2. 切换后刷新不生效
   - 检查 `localStorage['theme-mode']` 是否写入。
3. `system` 不跟随系统变化
   - 检查浏览器是否支持 `matchMedia('(prefers-color-scheme: dark)')`。
   - 确认当前 mode 为 `system`。
