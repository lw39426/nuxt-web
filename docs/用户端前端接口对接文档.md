# 用户端前端接口对接文档

本文档基于当前后端代码 `applications/view/user` 实际路由整理，可直接用于 H5/小程序/APP 前端联调。

## 1. 基础信息

- API 基础前缀：`/api/v1`
- 数据格式：`application/json`
- 编码：`UTF-8`

## 2. 统一请求约定

### 2.1 认证头

需要登录的接口统一使用 JWT：

```http
Authorization: Bearer <access_token>
```

### 2.2 通用返回结构

项目中存在两种风格，前端需兼容：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {},
  "success": true
}
```

或（部分接口无 `success` 字段）：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

建议前端以 `code === 200` 作为成功判定主条件。

### 2.3 常见错误码

- `200`：成功
- `400`：参数错误/业务校验失败
- `401`：未登录或 token 失效
- `403`：无权限或账号禁用
- `404`：资源不存在
- `500`：服务器异常

## 3. 认证与登录流程

### 3.1 推荐流程

1. 根据后端配置决定是否先拉验证码：`GET /api/v1/auth/getCode`
2. 登录：
   - 微信登录：`POST /api/v1/auth/wxLogin`
   - 手机号登录：`POST /api/v1/auth/loginByPhone`
   - 用户名登录：`POST /api/v1/auth/loginByUsername`
3. 保存 `access_token` 与 `refresh_token`
4. `access_token` 过期后，调用 `POST /api/v1/auth/refreshToken` 刷新
5. 退出登录调用 `GET /api/v1/auth/logout`

### 3.2 认证接口

#### 1) 获取验证码
- 路径：`GET /api/v1/auth/getCode`
- 说明：返回验证码图片 base64 和 `captcha_key`
- 返回示例：

```json
{
  "code": 200,
  "message": "验证码生成成功",
  "data": {
    "captcha_key": "abcd1234efgh5678",
    "image": "data:image/png;base64,..."
  },
  "success": true
}
```

#### 2) 微信登录
- 路径：`POST /api/v1/auth/wxLogin`
- 请求体：

```json
{
  "code": "wx_code",
  "userInfo": {
    "nickName": "昵称",
    "avatarUrl": "头像URL",
    "gender": 1,
    "country": "CN",
    "province": "Guangdong",
    "city": "Shenzhen"
  }
}
```

#### 3) 手机号登录
- 路径：`POST /api/v1/auth/loginByPhone`
- 请求体：

```json
{
  "phone": "13800000000",
  "password": "123456",
  "captcha": "1234",
  "captcha_key": "abcd1234efgh5678"
}
```

> 当后端 `OPEN_CAPTCHA=true` 时，`captcha` 和 `captcha_key` 必填。

#### 4) 用户名登录
- 路径：`POST /api/v1/auth/loginByUsername`
- 请求体：

```json
{
  "username": "test_user",
  "password": "123456",
  "captcha": "1234",
  "captcha_key": "abcd1234efgh5678"
}
```

#### 5) 兼容登录（旧版）
- 路径：`POST /api/v1/auth/login`
- 说明：`phone` 或 `username` 二选一，必须有 `password`

#### 6) 注册
- 路径：`POST /api/v1/auth/register`
- 请求体：

```json
{
  "phone": "13800000000",
  "password": "123456",
  "nickname": "张三",
  "captcha": "1234",
  "captcha_key": "abcd1234efgh5678"
}
```

#### 7) 刷新 token
- 路径：`POST /api/v1/auth/refreshToken`
- 认证：`refresh_token`（Bearer）

#### 8) 退出登录
- 路径：`GET /api/v1/auth/logout`
- 认证：`access_token`（Bearer）

## 4. 首页与公共数据接口（无需登录）

### 4.1 首页聚合
- `GET /api/v1/home/data`：首页聚合数据（banner/分类/精选/热门/文章/新品）

### 4.2 Banner
- `GET /api/v1/banners?placement_key=home_top_banner`

### 4.3 首页分类与商品
- `GET /api/v1/home/categories`
- `GET /api/v1/home/category/{category_id}/products?page=1&limit=10&sort_by=create_time&sort_order=desc`
- `GET /api/v1/home/featured-products?page=1&limit=10`
- `GET /api/v1/home/hot-products?page=1&limit=10`
- `GET /api/v1/new-products?page=1&limit=10`

### 4.4 首页文章与标签
- `GET /api/v1/home/articles?page=1&limit=10&category_id=1`
- `GET /api/v1/tags?type=1`

## 5. 商品模块（无需登录）

前缀：`/api/v1/product`

- `GET /api/v1/product/{product_id}`：商品详情
- `GET /api/v1/product/search?page=1&per_page=10&keyword=...&category_id=...&min_price=...&max_price=...&sort_by=price|sales|create_time&sort_order=asc|desc`
- `GET /api/v1/product/category/list`：分类列表
- `GET /api/v1/product/category/{category_id}/products?page=1&limit=10`

## 6. 文章模块（无需登录）

前缀：`/api/v1/article`

- `GET /api/v1/article/list?page=1&limit=10&category=...&keyword=...&sort_by=published_date|views|likes|comment_count&order=desc|asc`
- `GET /api/v1/article/{article_id}`：文章详情（会增加阅读量）
- `GET /api/v1/article/{article_id}/related?limit=5`
- `GET /api/v1/article/categories?include_count=true|false`
- `GET /api/v1/article/tags`
- `GET /api/v1/article/hot?limit=10`
- `GET /api/v1/article/latest?limit=10`
- `GET /api/v1/article/search?keyword=...&page=1&limit=10`

## 7. 评论模块（部分需登录）

前缀：`/api/v1/comments`

- `POST /api/v1/comments/create`（需登录）
  - 请求体：`article_id`、`content`、可选 `parent_id`、`reply_to_user_id`
- `GET /api/v1/comments/article/{article_id}?page=1&per_page=20&sort_by=created_at|like_count&order=desc|asc`（需登录）
- `POST /api/v1/comments/{comment_id}/like`（需登录）
- `DELETE /api/v1/comments/{comment_id}/delete`（需登录，仅作者可删）
- `GET /api/v1/comments/user/{user_id}?page=1&per_page=20&include_deleted=false`（需登录）
- `GET /api/v1/comments/statistics/{article_id}`（无需登录）

## 8. 收藏模块（需登录）

前缀：`/api/v1`

- `POST /api/v1/favorite/toggle`
  - 请求体：`item_type`（`article`/`product`）、`item_id`
- `POST /api/v1/favorite/check`
- `GET /api/v1/favorite/list?type=article|product&page=1&per_page=10`
- `GET /api/v1/favorite/count`
- `POST /api/v1/favorite/remove`
  - 请求体：`favorite_ids`（数组）
- `POST /api/v1/favorite/clear`
  - 请求体：可选 `item_type`

## 9. 用户资料模块（需登录）

前缀：`/api/v1/user`

- `GET /api/v1/user/info`：完整用户信息
- `POST|PUT /api/v1/user/updateInfo`：更新用户资料
  - 可传字段：`nickname`、`username`、`phone`、`gender`、`birthday(YYYY-MM-DD)`、`address`、`country`、`province`、`city`、`avatar`、`bg_cover`、`description`
- `POST /api/v1/user/updatePassword`
  - 请求体：`oldPassword`、`newPassword`
- `GET /api/v1/user/profile`：简要资料
- `POST /api/v1/user/bindPhone`
  - 请求体：`phone`
- `POST /api/v1/user/bgCover`
  - `multipart/form-data` 上传，字段名：`file`

## 10. 地址模块（需登录）

前缀：`/api/v1/user/addresses`

- `GET /api/v1/user/addresses`：地址列表
- `POST /api/v1/user/addresses`：新增地址
  - 请求体：`recipient_name`、`phone`、`address_line`、`is_default`
- `PUT /api/v1/user/addresses/{address_id}`：更新地址
- `DELETE /api/v1/user/addresses/{address_id}`：删除地址
- `PUT /api/v1/user/addresses/{address_id}/setDefault`：设为默认
- `GET /api/v1/user/addresses/default`：获取默认地址

## 11. 购物车模块（需登录）

前缀：`/api/v1/cart`

- `GET /api/v1/cart/list`：购物车列表
- `POST /api/v1/cart/add`
  - 请求体：`product_id`、`quantity`
- `PUT /api/v1/cart/update/{cart_item_id}`
  - 请求体：`quantity`
- `DELETE /api/v1/cart/del/{cart_item_id}`
- `DELETE /api/v1/cart/clear`

## 12. 订单模块（需登录）

前缀：`/api/v1`

- `POST /api/v1/orders`：创建订单
  - 请求体：`address_id`
  - 说明：当前实现默认按“购物车全选”下单
- `GET /api/v1/orders?page=1&per_page=10&status=0`
- `GET /api/v1/orders/{order_id}`
- `POST /api/v1/orders/{order_id}/cancel`
- `POST /api/v1/orders/{order_id}/pay`（模拟支付）
- `POST /api/v1/orders/{order_id}/confirm`

订单状态：
- `0` 待支付
- `1` 已支付
- `2` 已发货
- `3` 已完成
- `4` 已取消
- `5` 已退款

## 13. 地区与角色模块（无需登录）

前缀：`/api/v1`

- `GET /api/v1/regions`：地区列表（含启用角色）
- `GET /api/v1/regions/{region_code}?page=1&per_page=10`：地区详情+角色（分页可选）
- `GET /api/v1/characters?page=1&per_page=10&region_code=...&element=...&keyword=...`
- `GET /api/v1/characters/{character_code}`

## 14. 前端联调注意事项

1. `Authorization` 统一使用 `Bearer access_token`，刷新接口使用 `refresh_token`。
2. 部分接口返回包含 `success`，部分不包含，建议只用 `code` 判定成功。
3. 上传背景封面接口是 `multipart/form-data`，不是 JSON。
4. 评论列表接口目前要求登录（`jwt_required`），未登录会返回 401。
5. 登录相关接口是否强制验证码，受后端配置 `OPEN_CAPTCHA` 控制。

## 15. 建议的前端封装

- 请求拦截器：自动注入 `Authorization`。
- 响应拦截器：统一处理 `401`（刷新 token 或跳登录页）。
- 错误提示：优先展示 `message`。
- 分页参数统一：优先兼容 `page + per_page`，对于部分接口使用 `limit` 时在前端做适配层。
