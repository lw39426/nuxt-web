## 基础配置

### API Base URL

```
开发环境: http://localhost:5050/api/v1
生产环境: https://your-domain.com/api/v1
```

### 统一请求返回格式

所有接口返回统一的 JSON 格式：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

部分接口（尤其认证模块历史接口）会额外返回 `success` 字段（`true` / `false`）作为兼容标记，前端可忽略该字段，以 `code` 与 `message` 为准。

错误响应通常包含以下结构：

```json
{
  "code": 400,
  "msg": "技术详情或兼容字段",
  "message": "用户可读提示",
  "data": null
}
```

### 通用错误码

| 码值 | 说明 |
|------|------|
| `200` | 操作成功 |
| `400` | 参数验证失败或业务逻辑错误 |
| `401` | 未登录或 Token 失效 |
| `404` | 资源不存在 |
| `500` | 服务器异常 |

### 分页参数约定

**请求参数**（统一）:

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| page | Integer | 1 | 页码，从 1 开始 |
| pageSize | Integer | 10 | 每页数量 |

**响应结构**（统一 `pagination` 对象）:

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "列表数据": [ /* ... */ ],
    "pagination": {
      "page": 1,
      "pageSize": 10,
      "total": 50,
      "pages": 5
    }
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| page | Integer | 当前页码 |
| pageSize | Integer | 每页数量 |
| total | Integer | 总记录数 |
| pages | Integer | 总页数 |

> **注意**: 除首页聚合接口 `/home/data` 外，所有列表接口均使用此分页约定。

### 鉴权说明

需要登录的接口通过 **JWT Token** 鉴权，请求头携带：

```
Authorization: Bearer <access_token>
```

Token 通过 `/auth/login` 系列接口获取，过期后使用 `/auth/refreshToken` 刷新。

### 时间格式

- 响应中的时间字段均为 **UTC ISO8601** 格式，如 `"2026-07-07T06:58:00Z"`
- 前端需自行转换为本地时区显示

## 商品模块

> **前缀**: `/api/v1/product`
> **无鉴权要求** — 商品信息属于公开数据

### 1. 获取商品详情

**接口地址**: `GET /api/v1/product/<product_code>`

**URL 参数**:

| 参数 | 类型 | 说明 |
|------|------|------|
| product_code | String | 商品业务ID（必填），自动去除首尾空格并转为小写 |

**请求示例**:

```javascript
fetch('/api/v1/product/iphone-17-pro')
  .then(res => res.json())
  .then(data => console.log(data));
```

**响应格式**:

```json
{
  "code": 200,
  "message": "获取商品详情成功",
  "data": { /* 商品对象 Product */ }
}
```

**缓存说明**: 支持 Redis 缓存，TTL 默认 120 秒

**错误响应**:

```json
{ "code": 404, "message": "商品不存在或已下架" }
```

---

### 2. 商品搜索

**接口地址**: `GET /api/v1/product/search`

**请求参数** (Query):

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| page | Integer | 1 | 页码 |
| pageSize | Integer | 10 | 每页数量 |
| keyword | String | '' | 关键字（商品名称模糊匹配） |
| category_id | Integer | - | 分类ID筛选 |
| min_price | Float | - | 最低价格 |
| max_price | Float | - | 最高价格 |
| sort_by | String | `create_time` | 排序字段：`create_time` \| `price` \| `sales` |
| sort_order | String | `desc` | 排序方向：`asc` \| `desc`（`sales` 始终降序） |

**请求示例**:

```javascript
// 搜索手机类商品，按价格升序
fetch('/api/v1/product/search?keyword=iPhone&category_id=2&sort_by=price&sort_order=asc')
  .then(res => res.json())
  .then(data => console.log(data));
```

**响应格式**:

```json
{
  "code": 200,
  "message": "搜索商品成功",
  "data": {
    "products": [ /* 商品对象数组 */ ],
    "pagination": {
      "page": 1,
      "pageSize": 10,
      "total": 50,
      "pages": 5
    }
  }
}
```

---

### 3. 获取商品分类树

**接口地址**: `GET /api/v1/product/category/list`

**请求参数**: 无

**请求示例**:

```javascript
fetch('/api/v1/product/category/list')
  .then(res => res.json())
  .then(data => console.log(data));
```

**响应格式**:

```json
{
  "code": 200,
  "message": "获取分类列表成功",
  "data": [
    {
      "id": 1,
      "name": "手机数码",
      "imageUrl": "https://...",
      "children": [
        { "id": 11, "name": "智能手机", "imageUrl": "...", "children": [] },
        { "id": 12, "name": "耳机", "imageUrl": "...", "children": [] }
      ]
    }
  ]
}
```

---

### 4. 获取分类下的商品

**接口地址**: `GET /api/v1/product/category/<category_id>/products`

**请求参数**:

| 参数 | 位置 | 类型 | 默认值 | 说明 |
|------|------|------|--------|------|
| category_id | 路径 | Integer | - | 分类ID（必填） |
| page | Query | Integer | 1 | 页码 |
| pageSize | Query | Integer | 10 | 每页数量 |
| sort_by | Query | String | `create_time` | 排序：`create_time` \| `sales` \| `price` |
| sort_order | Query | String | `desc` | 方向：`asc` \| `desc` |

**请求示例**:

```javascript
fetch('/api/v1/product/category/2/products?page=1&pageSize=10&sort_by=price&sort_order=asc')
  .then(res => res.json())
  .then(data => console.log(data));
```

**响应格式**:

```json
{
  "code": 200,
  "message": "获取分类商品成功",
  "data": {
    "category_name": "手机",
    "products": [ /* 商品对象数组 */ ],
    "pagination": {
      "page": 1,
      "pageSize": 10,
      "total": 25,
      "pages": 3
    }
  }
}
```

## 购物车模块

> **前缀**: `/api/v1/cart`
> **需要鉴权** — 所有接口

### 1. 获取购物车列表

**接口地址**: `GET /api/v1/cart/list`

**请求参数**: 无（从登录态获取当前用户）

**响应格式**: `[ /* 购物车项，含商品对象 */ ]` + `total_price`

---

### 2. 加入购物车

**接口地址**: `POST /api/v1/cart/add`

> ⚠️ 实测后端以 `product_code`（商品编码，如 `prd_25`）定位商品，
> 文档原先写的 `product_id` 会被后端以「参数错误」拒绝（2026-09 实测）。

**请求体**:

```json
{
  "product_code": "prd_25",
}
---

### 3. 更新购物车项数量

**接口地址**: `PUT /api/v1/cart/update/<cart_item_id>`

**请求体**:

```json
{
  "quantity": 3
}
```

---

### 4. 删除购物车项

**接口地址**: `DELETE /api/v1/cart/del/<cart_item_id>`

**URL 参数**:

| 参数 | 类型 | 说明 |
|------|------|------|
| cart_item_id | Integer | 购物车项ID |

---

### 5. 清空购物车

**接口地址**: `DELETE /api/v1/cart/clear`

## 认证模块

> **前缀**: `/api/v1/auth`
> **无鉴权要求**

### 1. 微信登录

**接口地址**: `POST /api/v1/auth/wxLogin`

**请求体**:

```json
{
  "code": "微信wx.login()获取的code",
  "nickname": "用户昵称",
  "avatar": "头像URL"
}
```

**响应格式**:

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "access_token": "eyJhbG...",
    "refresh_token": "eyJhbG...",
    "user": { /* 用户信息 */ }
  }
}
```

---

### 2. 手机号登录

**接口地址**: `POST /api/v1/auth/loginByPhone`

**请求体**:

```json
{
  "phone": "1*********0",
  "code": "123456"
}
```

---

### 3. 用户名登录

**接口地址**: `POST /api/v1/auth/loginByUsername`

**请求体**:

```json
{
  "username": "testuser",
  "password": "******"
}
```

---

### 4. 通用登录

**接口地址**: `POST /api/v1/auth/login`

支持多种账号体系（微信 / 手机 / 用户名），根据请求体字段自动识别登录方式。

---

### 5. 注册

**接口地址**: `POST /api/v1/auth/register`

**请求体**:

```json
{
  "username": "newuser",
  "password": "******",
  "phone": "1*********0",
  "code": "123456"
}
```

---

### 6. 刷新 Token

**接口地址**: `POST /api/v1/auth/refreshToken`

**鉴权要求**: 需要在请求头中携带 `refresh_token`（不是放在请求体）

```http
Authorization: Bearer <refresh_token>
```

**响应格式**:

```json
{
  "code": 200,
  "message": "Token刷新成功",
  "data": {
    "access_token": "eyJhbG...",
    "token_type": "Bearer"
  },
  "success": true
}
```

---

### 7. 登出

**接口地址**: `GET /api/v1/auth/logout`

**需要鉴权**

---

### 8. 获取验证码

**接口地址**: `GET /api/v1/auth/getCode`

**请求参数** (Query):

| 参数 | 类型 | 说明 |
|------|------|------|
| phone | String | 手机号 |

## 收藏模块

> **前缀**: `/api/v1`
> **需要鉴权**

### 1. 收藏 / 取消收藏（切换）

**接口地址**: `POST /api/v1/favorite/toggle`

**请求体**:

```json
{
  "item_type": "product",
  "item_id": 18
}
```

| 参数 | 类型 | 说明 |
|------|------|------|
| item_type | String | 收藏类型：`product`（商品） \| `article`（文章） |
| item_id | Integer | 商品/文章ID |

**响应格式**:

```json
{
  "code": 200,
  "message": "收藏成功",
  "data": {
    "is_favorited": true
  }
}
```

---

### 2. 检查是否已收藏

**接口地址**: `POST /api/v1/favorite/check`

**请求体**: 同 toggle

**响应格式**:

```json
{
  "code": 200,
  "data": {
    "is_favorited": true
  }
}
```

---

### 3. 获取收藏列表

**接口地址**: `GET /api/v1/favorite/list`

**请求参数** (Query):

| 参数 | 类型 | 默认值 | 说明 |

| page | Integer | 1 | 页码 |
| pageSize | Integer | 10 | 每页数量 |
| item_type | String | - | 筛选：`product` \| `article`，不传返回全部 |

**响应格式**:

```json
{
  "code": 200,
  "data": {
    "favorites": [
      {
        "id": 1,
        "item_type": "product",
        "item_id": 18,
        "item_title": "iPhone 17 Pro",

---

### 4. 获取收藏数量

**接口地址**: `GET /api/v1/favorite/count`

**请求参数** (Query):

| 参数 | 类型 | 说明 |
|------|------|------|
| item_type | String | 可选，不传返回总数 |

---

### 5. 移除收藏

**接口地址**: `POST /api/v1/favorite/remove`

**请求体**:

```json
{

  "item_id": 18

### 6. 清空收藏

**接口地址**: `POST /api/v1/favorite/clear`

### 前后端协作注意事项

1. **价格单位**：商品价格为"分"（整数），前端展示时需除以 100 转换为"元"。
2. **时间处理**：所有时间字段为 UTC，前端须自行转换本地时区。
3. **Token 刷新**：access_token 过期时先调 `/auth/refreshToken`，refresh_token 也失效时需重新登录。
4. **列表字段一致性**：2026-07 起商品类列表接口（搜索、分类、首页等）统一返回 `to_dict()` 完整字段，含 `sale_price`、`status`、`sort`、`brand`、`tags`、`create_time`、`update_time`、`favorite_count`、`main_image`、`images`、`detail_html`。
5. **分页参数已统一**：所有列表接口统一使用 `page` / `pageSize` 作为请求参数，响应中通过 `pagination.{page, pageSize, total, pages}` 返回分页信息。
6. **错误处理**：请优先以响应体中的 `code` / `message` 判定业务结果。历史接口中存在“HTTP 状态码为 200 但 `code` 为非 200”的兼容行为，建议前端统一按业务码拦截。
