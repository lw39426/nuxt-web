# 博客筛选面板与叠卡轮播的滑动设计

博客页有两个可以左右滑动的区域。分类和标签面板的手势在浏览器滚动层处理，滑动的结果是停在某一页筛选项。叠卡轮播的手势由组件处理，滑动的结果是切换中央卡片。理解两者时，可以先看「手指移动时改了什么」和「松手后由谁决定落点」。

| 区域 | 滑动时变化的值 | 松手后的落点 | 是否改变业务选中项 |
| --- | --- | --- | --- |
| 分类与标签面板 | 滚动容器的 `scrollLeft` | 浏览器将容器吸附到分页起点 | 滑动只改变可见的筛选项。点击某一项才改变分类或标签。 |
| 叠卡轮播 | 叠卡舞台的 CSS 变量 `--drag` | composable 判断切到相邻卡，或回到当前卡 | 达到切卡条件时改变当前轮播索引。 |

## 筛选面板

### 用真实排版计算分页

[BlogFilterPanel.vue](../app/components/BlogFilterPanel.vue) 接收 `options`、`selected` 和展示配置，点击选项时发出 `select`。博客页负责保存当前分类、标签，并根据选中项更新文章列表。[博客页接入](../app/pages/blog/index.vue)

组件渲染一份不可见的测量区 `probe`。测量区与实际选项使用相同的标签样式和横向间距，浏览器会按当前容器宽度自动换行。组件读取每个标签的 `offsetTop`，把顶部位置相同的标签归到同一行。展开状态下每两行组成一页。这样，长标签占用更多宽度，窄屏也会自然减少每页的选项数。

分类一直展开，标签默认只显示首行。标签展开时查找选中项所在行，再以 `Math.floor(行索引 / 2)` 定位到对应页。容器尺寸、选项或字体度量变化后会重新测量，并把当前页限制在新的有效范围内。

### 横滑、吸附和页码同步

分页容器 `.filter-track` 用 `overflow-x: auto` 开启横向滚动，每个 `.filter-content` 占满一页宽度。触屏滑动时浏览器直接更新滚动位置，并处理惯性。容器通过 `scroll-snap-type: x mandatory` 启用吸附，分页用 `scroll-snap-align: start` 将左边缘作为落点，`scroll-snap-stop: always` 限制快速滑动跨过吸附点。

组件在被动 `scroll` 监听中读取 `scrollLeft`，用它除以页间距，再四舍五入得到最接近的页码。页间距取第二页的实际 `offsetLeft`，包含页间留白。标签展开后的上一页、下一页按钮也使用实际页位置调用 `scrollTo()`。普通模式平滑滚动，开启减少动效时直接跳转。

```text
手指横滑 → 浏览器更新 scrollLeft → CSS 吸附到分页起点
                     ↳ scroll 监听同步页码
点击标签 → 发出 select → 博客页更新筛选 → 重新请求文章
```

## 叠卡轮播

### 通过索引排出中央卡片和两侧预览

[BlogHeroCarousel.vue](../app/components/BlogHeroCarousel.vue) 以当前索引为基准，为每张卡计算循环距离。距离为零的卡居中，正负距离决定卡片出现在右侧或左侧，距离绝对值控制缩放、透明度和层级。CSS 把相对位置与整个舞台共用的 `--drag` 相加，所以拖动时多张卡一起移动。

当列表只有两条内容时，组件把唯一的侧卡额外镜像到左侧。左右预览指向同一条数据。当前改动让窄屏也显示这张镜像侧卡。点侧卡先将它切到中央，中央卡有链接时才会打开对应页面。

### 用 Pointer Events 计算跟手位移

[useStackedCarousel.ts](../app/composables/useStackedCarousel.ts) 在主指针按下时记录指针 ID、起点和起始元素，并暂停自动播放。后续在窗口监听 `pointermove`、`pointerup` 和 `pointercancel`，让指针离开卡片时也能正常结束手势。舞台上的 `touch-action: pan-y` 保留浏览器的纵向页面滚动。

横向位移大于纵向位移时，用 `clamp(dx × 0.3, -60, 60)` 计算卡片偏移，单位为像素。位移按比例缩小，因此手指拖动 100px 时，卡片的目标位移是 30px。位移通过 `--drag` 进入卡片的 CSS `transform`，卡片保留自身过渡，所以实际画面会追随目标位置。

松手时，只有横向位移**超过 40px** 且大于纵向位移才切卡。左滑进入下一张，右滑进入上一张。短距离拖动和取消手势会把 `--drag` 归零并回到当前卡片。切卡时 `goTo()` 用取模处理首尾循环，索引更新独立于 CSS 过渡的结束时机。

为避免拖动结束时误打开链接，组件会检查位移和松手所在元素，在需要时拦截紧接着的指针点击。自动播放则等拖动、悬停、聚焦或页面隐藏等暂停原因全部解除后再计时。开启减少动效时，手动切换仍可使用，自动播放和相关过渡停用。

```text
按下记录起点 → 横向移动计算 --drag → 松手判断方向和 40px 阈值
                                        ├─ 达标 → 更新索引并清除 --drag
                                        └─ 未达标或取消 → 清除 --drag，保留索引
```

## 验证要点

- **筛选面板**。在窄屏滑动展开的标签，观察松手后的吸附、页码和按钮禁用状态。切换设备宽度，检查每页仍按实际换行分组。单独点击标签，确认才会更新文章列表。
- **叠卡轮播**。用两张图检查左右预览，短滑回到当前卡，长滑触发切换，纵向滑动仍能滚动页面。再检查首尾回环和拖动后是否误打开链接。
- **减少动效**。筛选分页按钮应直接定位，轮播仍可手动切换，且不会自动播放。轮播已有单测覆盖双向循环、重叠暂停原因和数据缩减。[轮播单测](../tests/unit/composables/useStackedCarousel.test.ts)
